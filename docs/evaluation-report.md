## 主要残余风险与发布条件

1. 由独立模型按同一 50 项场景至少重复三次，记录真实模型、工具和知识快照；
2. 由中国大陆执业律师重点复核自认、程序路由、举证责任、来源状态和拟对外稿闸门；
3. 对失败场景修订后重新测试，不能用平均分抵消虚构引文、未授权自认、隐私外泄或冒名签发；
4. 只有上述行为门和法律门通过后，才把 `working_draft_only` 提升为 `reviewed`；
5. P2 另行授权后再建设来源索引、地方资料和受控抓取，不在 P1 内夸大。

# 持衡插件与共享法库：Windows 10 原生迁移设计

日期：2026-10-09。状态：用户已确认 Windows 10 原生迁移设计，进入实施；尚未生成新迁移包或完成 Windows 实测。

## 1. 交付目标

把本机现有持衡插件、审查 Skill、民商事一审模拟法庭和共享法库迁往用户自己的 Windows 电脑。首次安装允许联网下载依赖，不使用 WSL，不公开发布，不要求购买云服务。Mac 原安装继续保留。

“完整打包”指当前已有程序、方法资料、公开法库及其来源证据完整交付，不表示全国法律数据库、会员来源或全部模拟庭审程序已经完成。

目标系统为 Windows 10，不要求升级 Windows 11，也不使用 WSL。处理器架构暂按 Intel/AMD x64，测试基线暂按22H2；这两项是设计假设，并非用户已确认的电脑配置。安装前检测实际版本、构建号、架构和运行环境；LTSC、较早版本、32位或ARM设备单独判断，不宣称所有 Windows 10 版本均支持，也不自动升级操作系统。

系统安全支持与程序兼容性分开报告。微软列出的 Windows 10 Home/Pro 常规支持结束日期为2025-10-14；ESU和LTSC须按目标机实际版本及资格核对。安装器不代用户购买扩展支持，不把软件可以启动等同于系统仍获安全更新。

## 2. 一个总包，分别保留内容和运行环境

最终提供一个总 ZIP，附中文入口说明、文件清单、SHA-256 校验值、安装日志和分项检查报告。

包含：

- 当前插件与持衡 Skill，法律宝典共享检索 Skill，模拟法庭代码、模板和必要测试资料。保留上游许可证及来源说明。
- 当前公开库的数据库快照、原件、离线镜像、来源配置、审核记录、调度状态和追溯文件。复用现有 SQLite 备份与迁移校验，不直接复制运行中的数据库文件。
- 本项目必要的 Obsidian 项目笔记和公开法库导航；提供重新关联目标 vault 的入口，不复制整个 vault。历史证据中的 Mac 路径作为历史记录保留，新机器运行配置单独生成。
- Windows 安装、启动、检查、启用和停用自启动入口；故障说明及交接清单。
- Scrapling、bb-browser 和既有国家库/案例库客户端所需的程序、安装锁定信息或官方获取步骤。逐项盘点项目外依赖；可以随包带入的源码须核对许可证并剔除机器配置和凭据，不能带入的组件明确列出，不假称全离线包。

排除：账号密码、Cookie、会话令牌、浏览器用户资料目录、私人案卷、真实庭审会话、整份 Codex 配置、Mac 虚拟环境和 Mac 浏览器二进制。合成测试案件可在核对后收入。公共法律原件正常含有案情信息，不因文件名过滤便宣称已经完成隐私审核。

## 3. 必须适配的接口

### 3.1 并发与资料保护

现有多个入口使用 `fcntl.flock`，涉及资料更新、审查记录、模拟法庭和导出锁。增加一个小型共享跨平台锁接口，所有相关调用统一使用；保留 Mac 原有语义。Windows 的忙锁、阻塞、释放和异常退出必须有真实多进程检查。不能把 Unix 的建议锁直接机械替换成影响正文读写的 Windows 字节锁；实现前核对每个调用的打开方式、锁范围和生命周期，必要时统一使用独立锁文件。

迁移目录发布补 Windows 的禁止覆盖分支。解包同时检查路径穿越、Windows 保留名称、大小写碰撞、尾随点/空格、符号链接及重解析点、文件大小和清单一致性。拒绝覆盖旧安装或旧资料；失败保留可诊断状态，不删除用户旧目录。

### 3.2 安装与路径

保留 Mac 安装入口，增加 Windows 入口。复用已有备份、恢复、检索检查等能力，避免复制一套数据库逻辑。安装到用户可写的新目录，支持中文和空格；在最终目录创建 Windows 虚拟环境，不搬运旧环境。

检查 Python、SQLite FTS5/trigram、UTF-8、上海时区数据、PDF/表格组件和采集依赖。依赖版本按 Windows 重新解析核验，不直接宣称 Mac 锁文件可用；需要新增时区数据等平台依赖时记录原因和版本。缺少组件从可验证的官方来源或包仓库获取，下载失败报告具体缺项，不关闭 TLS、不修改全局执行策略。

Windows 10兼容核对先于安装锁定。Python文档列有覆盖Windows 10的版本，但具体补丁版本、分发来源及依赖组合仍须验证。安装入口不假设系统已具备winget、Microsoft Store或PowerShell 7；缺少下载工具时给出官方获取路径和明确提示，不把Windows 11专用组件作为隐含前提。

LibreOffice、浏览器、Node 和外部法律客户端分别检查。已有合适安装优先复用；不覆盖用户环境，不使用本机私有路径作为默认值。核心检索、模拟法庭、PDF、采集和浏览器各自报告可用性；可选依赖失败不会被包装成全部成功。

### 3.3 自启动与宿主连接

使用 Windows 原生任务计划机制，在当前用户登录后启动本机检索服务。安装时提供清楚的启用选项；用户选择并通过检查后自动注册。更新入口沿用现有到期、退避和补跑状态，检查频率保持现有五分钟，不改成反复全库抓取。

不保存 Windows 密码、不使用 SYSTEM 或最高权限、不修改其他计划任务；同名任务或端口冲突时停止并说明。只清理本次创建且身份核对一致的任务，停用自启动不删除法库。默认只监听 `127.0.0.1`。

原生 Codex 的 Skill/MCP 安装以目标机实际支持为准：提供专用入口，保留已有配置；同名内容有差异时不覆盖。未安装 Codex 时仍可准备法库并做本地检查，但不得声称插件已经接入。Windows 本机接入不等于 ChatGPT 云端接入。

### 3.4 浏览器与登录

Scrapling 浏览器在 Windows 重新下载和验证。bb-browser 保留固定版本、专用浏览器连接和连接失败即停止的边界，不回退扫描日常浏览器。Mac 上的补丁不能靠复制安装目录继承，须在 Windows 包中明确记录并重验。

2026-10-09核对的Playwright官方当前安装要求为Windows 11及以上（另列Windows Server/WSL），不包含Windows 10。这不能证明项目锁定版本必然无法启动，但不能据此宣称官方支持。实施时核对锁定版本及Scrapling、Patchright、Node、bb-browser和浏览器各自支持范围，并在Windows 10实测。不得为通过检查而静默降级到停止安全维护的浏览器。若无法获得可维护的兼容方案，保留全部资料和代码，明确列出浏览器自动化阻断及影响；任何功能替代或裁减先征求用户同意，不能把不完整功能标成“Windows 10完整版”。

人民法院案例库等账号在新电脑由用户正常登录，随后检查一次实际检索及正文读取；仅出现“登录成功”不算来源可用。登录到期提示用户，不承诺永久凭证。不扩展企查查、天眼查等会员权限，不绕过验证码或站点限制。

## 4. 验收与成功标准

1. 导出前后核对主库状态，不更改原数据。以打包时快照为准，逐项报告版本、来源、审计和镜像数量，不硬编码上轮的49版本作为永久基线。
2. 在干净目录恢复，核对所有清单文件和数据库逻辑内容，验证中文检索、来源卡和原文片段；原审核状态、撤回状态、文号和哈希保持不变。
3. 模拟法庭用合成案卷完成现有流程、记录保存和复练检查；不将合成测试称为律师效果验收。
4. 测试锁竞争、目录覆盖竞态、恶意压缩路径、中文空格路径、网络失败、端口冲突、依赖缺失及安装中断。原 Mac 回归须保持通过。
5. Windows 10 实机检查安装、实际 MCP 调用、浏览器公开页、计划任务和重登录自启动，记录真实系统版本、构建号及架构。只有实际可用的项目标记通过；没有目标机证据时明确“Windows 10 待实测”，不使用 Mac或Windows 11测试替代。
6. 总包再次解开核验，出具包含/排除清单、第三方来源和未完成项。缺外部组件会影响哪些功能必须能从报告直接看出。

包制作可先在 Mac 完成；原生 Windows 验收需要目标机。当前没有获得该电脑的执行连接，不假设可以直接访问或远程安装。

## 5. 保留的项目限制

全国正文覆盖、五份交通 XLS 的完整保真、会员来源实际连接、真实案件效果验收、ChatGPT 云端连接仍按已有报告列为未完成。迁移工作不顺带扩建全国库，也不改变引用时逐项说明来源并由用户审阅的规则。实验版、试用版不降低内容标准，保留最终警告和真实检查状态。

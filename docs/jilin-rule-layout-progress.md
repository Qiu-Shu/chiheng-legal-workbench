## 怎样验证没有为了入库漏掉正文

空隐藏占位仅在没有文字、没有子元素时允许忽略；有隐藏文字、图片、表格、脚本或未知结构则拒绝，不静默删除后冒充完整。标题、公布机关、发布机关和来源类型核对继续保留。

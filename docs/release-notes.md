# Release notes — 1.0.0-p1

## 新增

- 中文名称与显式调用入口：`持衡·中国诉讼攻防审查` / `$cn-litigation-redteam`。
- 审查对方文书、压力测试己方文书两种模式。
- 材料入口检查、中立风险底图、三遍审查和可审核处置记录。
- 中国大陆程序、举证、自认、版本、地域、来源和保密规则。
- 内部审查与待律师复核的拟对外稿分离。
- 案件输入、来源卡规则、攻击审计 Schema 和平台无关入口配置。

## 修改上游规则

- 默认改为简体中文和中国诉讼术语。
- 删除强制主动承认、至少两点、五点绝对上限、禁止限定语和必须比第一稿更短等绝对要求。
- 保留默认五点聚焦；允许 0/1 点和独立决定性争点突破。
- 上游美国示例不进入真实案例库；新增中文合成校准示例。

## 已知限制

- 这是 P1 方法包，不含法律数据库、客户资料、抓取依赖或后台服务。
- 50 项场景已定义但尚未完成独立模型和律师行为验收。
- 吉林、长春、松原地方资料尚未入库。
- 本版本不得宣传为可自动提交、无需复核或覆盖全国全部现行法律。

# 模拟法庭整改：事实与风险关联

2026年10月9日。本批完成 Task 4 的结构关联基础，适用于个人本机民商事一审演练。整体整改计划尚未完成。

## 本次可以做什么

每轮发言可以一并保存事实状态、支持及相反材料的精确文字位置、自认风险句、攻击点关联和辅助产物编号。程序核对材料哈希、引文和位置是否相符、关联对象是否存在；错引或悬空关联会阻止该轮保存。

需要更正时追加新回合，指向此前记录并说明原因，旧发言及快照保留。事实、风险和法库返回均存入同一会话文件，沿用现有锁和一次原子保存，没有新增数据库、服务或依赖。

审批字段只接受 null，关联自认风险的攻击点保留 blocked。此入口不能录入或认证真实律师审批，不能自动解除对外使用限制。已有 v2 回合没有 audit 时仍可读取；旧格式继续只读。旧运行时遇到带 audit 的新回合会拒绝，迁移时不能只复制单个 mock_hearing.py，须同时更新 hearing_audit.py 及相关组件。

## 如何使用

在现有模拟法庭请求中补充：

> 请把本轮事实状态、支持与相反材料、自认风险和攻击点关联一起保存；需要更正时保留旧记录，并说明更正针对哪一轮。所有审批保持待审。

助手按 Skill 的 audit 契约生成输入，仍走原 append 或 append-law 保存入口。用户无需手填字段。引文位置是已登记 UTF-8 文本的字符位置，不是 PDF 页码；原页和转换关系需另核。

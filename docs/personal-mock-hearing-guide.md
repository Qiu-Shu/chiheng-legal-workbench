# 个人本机模拟法庭：使用说明

首版范围是民商事一审内部演练，使用持衡 Skill 和共享法律库。其他程序继续使用原有文书审查能力，不套用这一套模拟流程。

## 怎样开始

在 Codex 新对话中指定本次材料，并说明我方角色。例如：

> 使用持衡进行民商事一审模拟法庭。我方是原告，只使用我这次指定的材料。先建立独立演练记录，再依次进行争点整理、举证质证、法庭发问、双方辩论和复盘。请逐轮与我互动，引用法律时显示来源、链接、条款位置及未核事项。

如需先试用，可以说：

> 使用明确虚构的材料，完整演练一次民商事一审模拟法庭。由同一模型分别模拟双方和主持，实际调用共享法库并保存每轮记录。最后读回记录确认，不作胜诉率预测或律师签发。

不用给所有案件目录权限；只指定本案文件。程序只接受整理后的UTF-8文本，最多100份、每份2MB。Word、PDF等先转换并保留原件和转换说明，不能把文本校验当作原格式已验收。

## 会留下什么

演练专用目录保存材料清单、实际文件哈希和 `session.json`。每轮分别记录角色、阶段、发言、材料编号、实际来源卡和未决问题；原告与被告不合并为一条记录。

暂停后可说“继续这个演练目录里的模拟法庭”。助手须先读回并验证保存记录与材料，不能只凭聊天记忆续写。材料变化或阶段不一致时会停止追加，不覆盖旧记录。完整复盘保存后，该会话结束；新演练另建目录。

2026年10月9日起，新会话采用v2格式，完整发言和来源记录纳入内容摘要校验。旧格式仍可原样查看，但不能续写；继续训练需要另建演练目录，保留旧记录。摘要用于发现未同步重算摘要的内容改变，不提供同账号防篡改或法律真实性保证。

新入口 `append-law` 会实际读取共享本地法库片段，将完整返回与本轮法律命题一起保存；不需要您手填引用卡。读取失败时不写入半条回合。引用展示仍包含具体来源、原文、定位和待核事项，取得本地原文不代表已完成联网现行性或法律适用审查。

复盘包含争点、双方强弱意见、证据缺口、可能追问、需改语句、待核法律和下一步。模拟主持的意见不是法院认定，模拟回答不是新的证据，缺材料不等于承认不利事实。

## 事实与风险怎样追溯

可要求助手“把本轮事实、支持与相反材料、自认风险和攻击点关联一起保存”。记录会保留事实状态、材料中的精确文字位置，以及风险句涉及哪些事实。程序核对文字是否与指定材料一致，不判断材料真假或该事实是否成立。

需要修正时另存当前回合，并指向之前的记录，旧内容不覆盖。辅助审计文本须在创建演练前列入材料清单；未列入的文件和原始 Word、PDF 不会因此自动冻结。

本入口只能记录待审批事项，不能填入律师姓名、审批决定或审批时间。旧回合未做结构化登记、登记为空，或程序保存成功，都不表示已无风险或可以对外使用。具体输入由助手按 Skill 参考页处理，无须您手写字段。

## 怎样追问、补强和复练

可以要求：“按争点逐个提问，记录哪些问题尚未回答、哪些任务已处理但待复查；不要把暂不能回答当作承认。”助手会将问题指向原告或被告，再把实际回应关联到相应问题。补充回答保留在新回合中，之前的回答不会被覆盖。

查看进度时，可说“列出这个演练目前的未答问题、补证任务和法律待核事项”。进度清单直接从保存记录中生成，不另维护一份容易过时的表。没有做过结构化跟踪的旧回合会明确标示，不能据空清单得出“没有缺口”。

补强任务只有“待处理”和“已处理、待复查”，不会自动变成律师已批准。法律命题另记事实日期、检索日期、时间效力、过渡规则和适用条件的待核说明；日期不明就保留未知。

完成一次演练后，可以指定旧演练目录、新目录、新材料和本次目标，要求建立关联复练。程序先校验旧记录，再新建一份空白回合记录；新旧须为同一案件、同一我方角色，且保持真实或合成材料标记一致。旧内容不会复制成新回答。

已有演练的材料清单保持不变。新增证据要在新演练中登记；同一演练内只能补充对已登记材料的定位和分析。复练关联保留旧记录的摘要和回合数，不保存依赖某台电脑的绝对路径，也不自动继承旧任务完成状态。

## 法律库怎样复用

持衡和其他法律助手共用本机 `chiheng-legal` 连接，不把同一份法库复制进每个Skill。先查 `legal_database_health` 和 `search_law`，再用 `get_law_article` 或 `get_law_fragment` 读回承担结论作用的原文。镜像检索另用 `search_public_corpus`，镜像结果仅作线索。

入库后可直接检索，但 `quarantine` 仍表示未经人工法律复核。引用时保留工具返回的名称、来源链接、原件链接、版本、条款或字符位置、时间和未知字段，由您当时审阅。未命中不等于无法律依据。

国家库 flk.npc.gov.cn 于2026-09-28观察到明确禁止自动采集，本项目相关自动入口已停止，不借其他接口绕过。已有原文可读，但不能据此保证今日现行性；可核对其他允许访问的官方来源或您提供的官方原件。

## 隐私、迁移与边界

- 会话在专用本机目录保存，不进入公共法库、Obsidian或分发包；Obsidian只记录项目状态和资料导航。
- 本机保存不等于模型在本地推理。真实材料进入Codex对话仍涉及模型服务传输，应遵循案件授权及保密要求。
- 同一模型可演不同角色，不是假装多个独立律师。不会形成真实当事人自认、预测胜率、提交法院或替律师签字。
- 会话文件检查只约束本模块，不是同一电脑账号下所有工具的隔离系统，也不是多用户案件授权系统。
- 共享源码包包含会话模块，Skill包不包含运行环境或完整法库。迁移到其他M芯片Mac仍按 `mac-migration-guide.md` 安装；不能只复制Skill就认为数据库和记录功能已配置。

实际验收范围见本次交付报告；合成测试不代替真实案件试用和律师复核。

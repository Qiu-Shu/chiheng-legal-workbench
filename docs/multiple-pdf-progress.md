# 多PDF核对续建（2026-09-28）

## 本轮计划及边界

1. 查明长春两条例的不同PDF是否存在实质正文差异。现有诊断显示：两种PDF按几何确认移除页脚后，双工具逐页正文一致；两PDF的去空白全文也与既有DOCX一致。严格边界检查失败仅限13/19页的页脚数字，均未超出物理页面，字宽框略超页脚裁剪框。不能据此放宽正文边界检查。
2. 先写失败测试：只有确实从两工具输出移除的页脚字形可以不进入正文裁剪检查，仍须在物理页面内，保留例外位置记录；正文/未知页脚/越界字形仍拒绝。
3. 多PDF不是任意择一：仅同名、最多3个PDF候选，全部严格提取且去空白正文等于所选正文，才能继续入库；逐一保存原件、哈希、对比记录，任一失败或差异停止。其他格式未比对仍披露。
4. 先验测试、再固定20样本实采、全文共享回读、独立复核和Obsidian更新。无自动法律审批、无全网扩抓/公开发布。

秸秆通知的两个PDF分别是10页公文版与4页网页打印版；后者含检索信息表格、标题及附件相关差异。不得套用长春正文相等结论，不能跳过失败原件。

## 实施结果

- 本轮固定20份真实重采：取得19份所选原件，16份入库/复用成功，4份失败。批次仍为`complete=false`；取得原件不等于正文已通过。
- 恢复长春永久基本农田保护、森林资源管理两条例。两份各自的两个PDF均严格提取通过，与所选DOCX去空白全文一致；4个PDF共64页。去空白一致不等于原件字节、排版、法律效力或全部附件一致。
- 原39版本ID全部保留，无新增版本、无重复计数；地方累计仍16。独立来源字段由35补至37版本，余2篇最高法网页仍明确缺失字段。人工审核发布仍0。
- 已重启本地只读服务加载引用卡字段；39版本默认检索、MCP全文回读及哈希通过，7工具通过。长春来源卡增加每个已比较PDF的原件链接/哈希、文字哈希、去空白文字哈希、总页数和比较结论；选用Word的正文没有错误套用PDF页码。
- 最终216项工程测试通过，0失败/错误/跳过。最终代码重放16份本轮成功原件，版本数和审计行数均不变；这是离线重放，不冒充另一次联网采集。

## 限定修复而非通用放宽

页脚字宽框略越活动裁剪框时，仅允许**已从两工具正文中删除的同页、同文字、同字形坐标**例外，并保存具体位置；所有字形仍检查MediaBox/CropBox物理范围。未知页脚、正文裁剪、物理越界仍拒绝。长春32页脚例外有留证，抽看农田第1页、森林第19页，页码可见；不是64页逐页视觉审阅。

真实重跑又发现WPS原件声明中性扩展图形状态。现在仅允许精确5键组合：Type=ExtGState、AIS=false、BM=Normal、CA=1、ca=1，逐页留证。任何额外键、缺键、不同值、透明/蒙版/其他混合状态继续拒绝。原有无例外PDF报告保持兼容，未重写原始PDF。

多PDF候选全部成功后才能保存来源。独立复核发现旧实现“正文先提交、来源后提交”可能在故障时留下不完整记录；已用失败测试复现并改为同一个实际事务保存正文、索引、审计、来源和回读检查。新增失败四表一起回滚，原件留证保留；旧版本来源冲突时完整保留旧数据。其他调用未传来源时保持原有行为。

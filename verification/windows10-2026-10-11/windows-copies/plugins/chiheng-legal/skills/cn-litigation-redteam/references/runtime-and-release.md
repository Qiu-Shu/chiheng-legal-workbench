# 运行与版本提示

实验版、律所试用版、生产版共用相同结构、分析深度、检索标准和成稿要求。不得因实验状态只交提纲、删减刑事或行政分析。必须按实际程序处理控辩、证明责任和证据合法性，不套用民事规则。

使用承担结论作用的法律规则、期限、管辖或程序救济时，自动使用宿主实际提供的法律检索工具；本地工具可用时先调用 `legal_database_health`、`search_law`，再用 `get_law_fragment` 核对上下文。

本机共享库也服务其他法律 Skill。用户当前用途为个人非商业学习；既有国家库/案例库 MCP 遵循其 CC BY-NC 4.0 等许可，不据此推定商业部署或公开发布授权。

- `public_corpus_inventory()`：离线镜像的版本、文本单元与分类数量。
- `search_public_corpus(query, law_title, category, limit)`：复用旧法规正文索引作候选发现，均为 unverified_mirror。
- `get_public_corpus_article(law_id, article, offset, length)`：返回精确条号，重复编号不静默合并。

镜像发现后须遵守来源当前访问限制。2026-09-28 两次实际读取 `flk.npc.gov.cn` 的 robots 均返回 200 并明确禁止自动采集；本项目停止对该域自动请求，不通过外部 MCP、`flk_search` / `flk_hit_display` 或更换端点绕过。已保存的官方原文可继续使用，但本次现行性未复核须就近注明；可继续检索其他允许访问的官方来源，或使用用户手动提供的官方原件。详情目录不是全文；关键词片段可能截断，不能据此宣称整条或整法完整。镜像上游的“有效”“核心已确认”等标签不是本系统审核结果。

- `search_law(query, as_of, region, include_quarantine=true, limit=10)`：默认检索已入库且未撤回资料；false仅筛人工审核版。日期YYYY-MM-DD，地域代码CN、CN-JL等。
- `get_law_fragment(version_id, offset=0, length=3000)`：取得原文及定位。
- `get_law_article(version_id, article, offset=0, length=5000)`：精确条号取文；有截断时继续分页，结构歧义时回看原件，不猜测分条。
- `legal_database_health()`：数量、完整性、发布状态。

资料通过机械检查即可入库，不逐份等待人工审阅；人工审阅移到实际引用时。quarantine表示未经人工法律复核，不等于不可检索，也不是现行有效证明。withdrawn只供历史审计，不作正常依据。as_of仅筛已确认的日期区间，日期未知资料会被排除；必要时取消日期过滤找线索，不据空结果下结论。

每一承担结论作用的法律命题须就地附来源卡和实际原文：名称、发布机关、文号、来源详情链接、原件链接、版本ID、条号/页码或字符位置、原件/文本哈希、采集时间、来源载明的公布/施行日期与已确认的适用日期、地域、审核状态。使用工具返回的citation，不用首页替代具体原文链接；未提供字段明确写未知，不能补造。source_dates是来源观察值，非人工确认；链接被返回不表示本次已经联网打开。输出待审引用卡不需先请用户批准，真正引用时由用户审阅版本、上下文和适用性。无命中后继续官方检索，法律库并非全国完整；检索工具不提供律师审批或发布权限。

企查查、天眼查网页会员由用户正常查询并官方导出；仅正式授权 API/MCP 可自动调用。内容交给云端模型会发生传输，先核对资料许可及案件授权；本地存储不代表本地推理。

实验版文末：本报告由实验版系统生成，使用与生产版相同的分析方法和输出标准；相关领域的数据覆盖、检索和行为验收尚未全部完成。对外使用前由承办律师依据原始材料和官方依据复核签发。

律所试用版文末：本报告由律所试用版系统生成，使用与生产版相同的分析方法和输出标准；已通过的测试以真实记录为准，尚未完成全部律师验收。对外使用前由承办律师复核签发。

生产版文末：本报告对应领域已完成所记录的验收。事实、证据、法律时效、期限、策略和签发仍由承办律师审定。

默认使用实验版提示；只有真实验收记录允许升级。个案不确定性放在相关结论处，不能仅靠文末警告处理。

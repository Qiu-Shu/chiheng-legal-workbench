# 当前摘要

此包迁移现有个人公开法库、持衡审查与模拟法庭程序、萌律 Skill 和必要外部客户端。公开资料数量、哈希、审核状态以交付内容清单和安装后健康检查为准；现有内容迁移不表示全国法规完整。

SQLite 的 quarantine 资料可检索，真实引用时展示完整来源卡、原文及缺失字段并审阅；镜像保留 unverified_mirror，不把来源观察日期当确认效力日期。MCP 无自动审核发布权限。

Windows 工程适配及 Mac 离线恢复检查与目标机验收分开记录。Windows 原生 ACL、PowerShell/计划任务、实际宿主、真实账号和浏览器需在新机验证。原 Mac 的已登录状态不会迁移。

本摘要依据本项目 2026-10-11 当前状态与交付过程整理；原项目记忆只手动读取必要当前片段，本轮没有收到钩子实际输出。没有复制历史全篇、全局偏好或整 vault。

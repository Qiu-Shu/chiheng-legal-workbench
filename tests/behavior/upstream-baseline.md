# 上游基线与预期失败

本记录是对上游 `SKILL.md` 的可复核指令级基线，不是一次独立模型运行。当前任务没有获准的独立子代理或律师评测，因此未伪造模型输出。

|中国版场景|上游明确指令|预期失败|
|---|---|---|
|B13 只有一个可持续观点|编号观点要求 2—5 个|可能凑到至少两个|
|B15 六项独立决定性争点|五点为绝对上限|可能遗漏决定性争点|
|B18 卷宗不完整|没有正式缺页和已读范围契约|可能把未提供材料写成不存在|
|B30/B31 程序混用|元数据写 `jurisdiction: All`，无中国程序路由|不能可靠阻断跨程序套用|
|B36/B37 来源校验|只要求工具可用时核验，没有结构/语义双层引用闸门|链接或入口可能被误当支持|
|B40 工具不可用|末尾绝对声称技能不联网、数据不外移|不能准确描述宿主实际数据流|
|B45/B46 新自认风险|要求开头主动、具体承认最强真实观点|可能未经审批新增对外承认|
|B49 离线现行法|无离线截止时间和降级契约|可能夸大现行性|
|B50 律师签发|无真实审批和签发字段|不能证明人工复核|

其余可继承价值：三遍审查、十类失败模式、最强回应/可信度测试、按承重程度排序、从头重建。中国版保留这些方法，但替换绝对规则并增加事实、程序、来源和审批控制。

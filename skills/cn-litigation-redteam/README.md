# 持衡·中国诉讼攻防审查

这是 `Sustainable Opposing Counsel Review` 的中国大陆实验版衍生 Skill。它保留“三遍审查”和十类失败模式，新增双模式、程序与地域路由、证据定位、自认审批、法律来源核验及内部/对外稿分离。

## 当前支持

- 民商事、劳动、执行、行政、仲裁、涉外及刑事：使用相同完整输出标准；均为实验状态，未完成全领域行为与律师验收。
- 刑事程序使用专门控辩和证据规则，不套用民事模板。
- 吉林、长春、松原：仅设置优先来源方向，地方增强资料尚未建成。

本包不内嵌全国法律数据库、客户材料、联网凭据或运行依赖。本机开发环境已安装Scrapling并建立小型待审核资料库；其他机器需单独配置。工具缺失时基于已提供材料完整分析，并在受影响结论旁说明未核验。

## 安装与调用

将顶层 `cn-litigation-redteam/` 文件夹安装到宿主支持的 Skill 目录。平台目录和安装方式可能变化，应以执行时官方说明为准。

按用户要求启用隐式调用，也可使用 `$cn-litigation-redteam` 显式调用。提供目标文书、模式、我方角色和预定用途；程序阶段、地区、关键日期、附件及证据定位按需补充。

## 输出与责任边界

默认先形成内部审查；条件满足且用户需要时，再单独生成标注“拟提交文本，待承办律师复核”的对外稿。Skill 不会替代承办律师进行事实确认、法律适用判断、授权审批或签发。
